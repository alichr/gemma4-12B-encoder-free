Encoder-FreeMultimodal Architecture

A local, reproducible study of google/gemma-4-12B-it — a model that ingests images and audio with no vision or audio encoder. Raw 48×48 pixel patches and raw 40 ms waveform frames are projected straight into the embedding space of a single 48-layer decoder-only LLM. This repo measures exactly how.

The pipeline

Raw signals in. No encoders between.

Each modality reaches the LLM through a handful of LayerNorm / Linear layers — not a ViT, not a Conformer. Image and audio become “soft tokens” scattered into the same sequence the text tokens live in.

IMAGE · 280 SOFT TOKENS

Vision embedder

48×48 patch (6912 px) → LN → Linear → LN
+ factorized 2D pos-emb → LN → RMSNorm → Linear(→3840)

tokenizer → scaled word-emb (×√3840)
UNIFIED DECODER-ONLY LLM · 11.91B

48 layers · 3840 dim

  • GQA 16 query / 8 KV heads
  • Hybrid attention — 40 sliding (win 1024) + 8 global, 5:1
  • p-RoPE on global layers · QK-norm · K=V sharing
  • 256K context · dense (no MoE)
  • → lm_head · 262,144 vocab
The receipts

The whole non-text path is 0.44% of the model.

If there were encoders, they'd show up in the parameter count. They don't.

language_model — 11.91B (99.56%)
language_model · 11.91B embed_vision · 49.9M embed_audio · 2.46M
Reconciling “~35M”: the vision path is 49.9M = a 35.2M patch embedder (the encoder replacement, matching Google's number) + 14.7M shared projection into LM space — the same module the audio path uses as its entire pipeline (a 2.46M Linear 640→3840).
Representation analysis · all 48 layers

What the layers do to each modality.

With no encoder, every bit of cross-modal "understanding" is built inside the shared stack. Probing and geometry localize where and how.

FIG · CROSS-MODAL

A fusion phase-transition at layer ~13

Image / audio / text centroids are near-orthogonal early, then snap to ~0.99 cosine and share a subspace through the mid-stack.

↳ modalities aren't aligned at input — the LLM aligns them.
FIG · ACTIVATION NORM

A massive-activation peak at layer ~23

Token norms collapse to a minimum near layer 11–12 (the alignment pivot), then spike together — an outlier regime shared across modalities.

↳ a mid-stack bottleneck, synchronized across modalities.
FIG · LINEAR PROBES

Color is linear at layer 0; shape needs a few layers

Low-level appearance is decodable straight from the linear patch projection; spatial structure forms over the first decoder layers.

↳ the embedder carries appearance; the LLM builds structure.
FIG · CKA

Input ≠ output representation

Layer-to-layer CKA of image tokens is high only locally; CKA(L0, L48) ≈ 0.07 — representations are transformed end to end.

↳ gradual, monotone evolution — no abrupt blocks.
Reproduce

One GPU. Synthetic inputs. No datasets.

bash — gemma4-12B-encoder-free
# environment (Blackwell sm_120 → cu128 wheels)
uv venv --python 3.12 .venv
uv pip install -r requirements-lock.txt
.venv/bin/hf download google/gemma-4-12B-it --local-dir ./models/gemma-4-12B-it

# run the study
.venv/bin/python scripts/01_architecture_report.py      # param anatomy (no weights)
.venv/bin/python scripts/02_modality_trace.py           # per-layer / per-modality shapes
.venv/bin/python scripts/03_linear_probes.py            # where semantics emerge
.venv/bin/python scripts/04_representation_geometry.py  # norms · anisotropy · CKA · alignment
.venv/bin/python scripts/05_build_report.py             # assemble the PDF
